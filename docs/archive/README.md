`> HISTORICAL` banner. Contents: the original handoff kit (START_HERE), dated session-context
handoffs (self-labeled disposable), the frozen Phase-1–5 review-cycle ledger, one-off

entries and point here.

`CLAUDE.md`; current state `docs/STATUS.md` + `TASKS.md`; decisions `docs/DECISIONS.md`;
