# Edge-Case Inventory (index)

Every financial calculation has unit tests pinned to a hand-verified table.
Those tables live **next to the tests** in `tests/edge-cases/` — one file per
section — so a session working a suite opens that file, not this dump.

This file is the index. Do not load it end-to-end looking for a number; open
the linked section. Amounts in the section files are shown in dollars for
readability; tests use integer cents. Calendar references use real 2026 dates
(June 13, 2026 = Saturday; June 15 = Monday).

If code and a table disagree, resolve on paper first — never adjust the
expected value to match the code.
